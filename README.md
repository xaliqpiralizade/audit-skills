# audit-skills

Claude Code üçün audit plugin-ləri: proqramı sahə mütəxəssisi (HR, maliyyə, anbar...) gözü ilə yoxlayan alətlər.

## Quraşdırma

```bash
/plugin marketplace add xaliqpiralizade/audit-skills
/plugin install domain-auditor@audit-skills
```

Lokal qovluqdan sınamaq üçün:

```bash
/plugin marketplace add ~/Desktop/audit-skills
```

## Plugin-lər

| Plugin | Təsvir |
|---|---|
| [domain-auditor](plugins/domain-auditor) | Hazır proqramı sahə auditoru (HR, maliyyə, anbar...) gözü ilə yoxlayır və Azərbaycan dilində risk dərəcələri olan audit hesabatı hazırlayır. Qanunvericilik bəndlərini e-qanun.az-dan mənbə linki ilə yoxlayır. Faylları dəyişmir. |
